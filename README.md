# 气象学 · Meteorology

An offline, trilingual (中文 / English / Bahasa Melayu) course in meteorology,
from how the atmosphere works to how ECMWF's ensemble forecasts are made, with
Malaysia as the running example. Static PWA — no build step, no npm
dependencies, no CDN.

## Run it

```bash
python3 tools/serve.py
```

Open <http://127.0.0.1:4190/>. Tests: `node --test tests/*.test.js`.
